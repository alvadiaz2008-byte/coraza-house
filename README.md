# Coraza House

Catálogo web de **Coraza House SAC** (muebles, Villa El Salvador). Muestra butacas Sirena, el escritorio vintage con espejo, el pack de escritorio y silla, y juegos de comedor.

Los precios de butaca (S/ 350), escritorio solo (S/ 650) y pack con silla (S/ 730) salen de los volantes de la tienda. Los juegos de mesa están con foto referencial y precio a consultar.

La página pública está en [alvadiaz2008-byte.github.io/coraza-house](https://alvadiaz2008-byte.github.io/coraza-house/). El archivo de entrada es [index.html](index.html), en la raíz del repositorio. GitHub Pages publica la rama `main`.

## Desarrollo

```bash
npm install
npm run dev
```
